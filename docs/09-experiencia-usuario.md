# Fase 9 — Experiencia de usuario

Diseño priorizando el celular. El flujo más importante del producto entero es **registrar un
gasto rápidamente**.

## Interacción ideal para registrar un gasto

1. Botón visible para agregar movimiento (accesible desde cualquier pantalla).
2. Monto como primer campo (teclado numérico inmediato).
3. Categoría sugerida (la más usada / la más probable según el momento).
4. Cuenta sugerida (la más usada por defecto).
5. Fecha actual por defecto (editable).
6. Descripción opcional.
7. Guardado rápido (un toque).
8. Confirmación clara (visual, no bloqueante).
9. Posibilidad de deshacer inmediatamente después de guardar.
10. Evaluar registro offline / tolerancia a conexión inestable (ver `11-tiempo-real-sincronizacion.md`).

## Pantallas principales

Inicio, Movimientos, Nuevo movimiento, Deudas, Préstamos, Moto, Ahorros, Presupuestos,
Calendario, Reportes, Categorías, Cuentas, Configuración, Importación, Auditoría.

## A cubrir para cada pantalla relevante

Navegación móvil y web, estados vacíos, estados de carga, estados de error, confirmaciones,
mensajes de validación, accesibilidad, diseño responsive, comunicación de estado sin depender
solo del color, formatos monetarios y de fecha configurables.
