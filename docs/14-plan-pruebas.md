# Fase 14 — Plan de pruebas

## Tipos de prueba a cubrir

Unitarias, integración, API, base de datos, interfaz, end-to-end, migración, concurrencia,
sincronización, seguridad, rendimiento, accesibilidad, recuperación, regresión.

## Casos de prueba mínimos

Registrar/editar/anular un gasto; registrar un abono; calcular saldo de una deuda; registrar
una cuota de moto; crear una meta de ahorro; importar Excel; detectar duplicados; operar sin
conexión; reintentar una operación fallida; evitar que un usuario consulte datos de otro
usuario.

Cada caso de prueba se detalla junto con el requisito funcional que valida (referenciar
`04-casos-de-uso.md` y `05-requisitos-funcionales.md`).
